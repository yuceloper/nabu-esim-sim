# v0.7 — Call Bridge

Opt-in on phone and runtime READ_PHONE_STATE, CALL_PHONE, ANSWER_PHONE_CALLS. Authenticated paired tablet can explicitly request ordinary outgoing call via TelecomManager.placeCall, answer via acceptRingingCall, and reject/end via endCall. No automatic dialing, retry, caller-ID collection, call history or audio transfer. Incoming generic notification, coarse idle/ringing/offhook states from polling; offhook includes dialing and active, not a connected-call confirmation. State epoch and short cooldown reduce stale commands, not a guarantee of individual call identity. Single ordinary call testing only; multi-call, call waiting, emergency calls unsupported. Android 10+ emergency-number check and full-number validation for dialing. Android deprecated answer/end APIs since API 29; actual ROM behavior must be tested, InCallService is later option. Phone default voice account used. User initiates each operation, carrier charges may apply. Re-pairing disables call sharing. No changes to native project or hotspot automation. Not compiled/device tested here. Test normal outgoing call, end, incoming notification, answer, reject and verify SMS remains working. On unknown result check phone before repeating.

Reference: https://developer.android.com/reference/android/telecom/TelecomManager
