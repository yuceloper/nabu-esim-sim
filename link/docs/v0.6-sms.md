# v0.6 — SMS bridge

Explicit opt-in on phone with SEND_SMS and RECEIVE_SMS runtime permissions. Uses configured default SMS subscription and authenticated encrypted requests from paired tablet. Tablet confirms recipient/content before send; host records unique request ID before submission to prevent retry duplicates. No automatic resend. Sent callback reports modem/Android send outcome, not recipient delivery. A timeout is unknown; check phone before retrying. Outgoing SMS is not inserted in phone system message history by this app; ROM behavior may vary. Incoming broadcast while host service runs; most recent three messages shown from ephemeral buffer of up to 20, body capped at 1000 characters. No historical inbox access, MMS, RCS, persistence, or full conversation UI. Generic private notification on tablet. New pairing disables SMS opt-in and clears buffer. SMS may contain sensitive content; only enable for own trusted tablet. No SMS body/recipient stored in ledger (request IDs only); ledger capped at 1000 attempts. Carrier charges may apply; long messages may require multiple segments. Android/ROM permission and foreground behavior require device tests. Not compiled or tested in connector environment. Instant hotspot postponed by user; native integration later.
