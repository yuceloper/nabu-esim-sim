# Nabu Link v0.1
Separate experimental app, same APK on ginkgo host and nabu client. Build with bash scripts/build-link-apk.sh (Android SDK 33, JDK). Trusted private LAN only, manual IP and random per-session code, TCP 37851, foreground activity, no SIM identifiers or messaging/call commands. Transport plaintext, token does not protect from LAN eavesdropping; do not use public Wi-Fi or forward port. Stop host after testing. Signal strength may be unavailable. No root, ROM modifications, hotspot automation, real virtual SIM, call/SMS handling or audio transport yet. Next: mutually authenticated encrypted transport, discovery, foreground service and permission-aware features. Not compiled/tested in connector environment. Native project remains on feature/vsim-cli.
