# v0.19 — Vayu donor baseline

Selected POCO X3 Pro Global (vayu) MIUI V14.0.3.0.TJUMIXM, Android 13, fastboot archive dated 2023-05-08, advertised size 5.6 GB. Same SoC family and Android generation as Nabu; this does not establish firmware compatibility.

Source: https://xmfirmwareupdater.com/miui/vayu/stable/V14.0.3.0.TJUMIXM/
Package: vayu_global_images_V14.0.3.0.TJUMIXM_20230508.0000.00_13.0_global_f76ca8a5c3.tgz
Published MD5: f76ca8a5c34ed4bd28d1c2729c864bbf

Use scripts/inspect-vayu-rom.sh on the local download. It validates the published MD5, inventories the archive, extracts only NON-HLOS.bin to a local directory, hashes it and attempts a read-only filesystem listing using macOS hdiutil. If hdiutil cannot recognize the image, use an offline FAT filesystem reader in the next iteration. All binary files stay local. No device connection or flashing required.

Next compare donor modem segment totals against Nabu 5,060,076 bytes, modem service registry metadata, MCFG payload presence and eventually DT/vendor radio configuration. No inference about RF hardware from size alone. Archive not yet acquired or inspected; script device-independent test pending.
