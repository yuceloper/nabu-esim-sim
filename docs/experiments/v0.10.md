# v0.10 — VSIM discovery

Run from repository root: `bash scripts/nabu-vsim-cli`.

Host-side prototype, not a native HIDL client. Requires adb, one selected Android device and authorized Magisk root. No direct HIDL method invocation, profile operations or radio changes.

Inspect daemon status, HAL registration rows, cellular QMI candidates and firmware hashes. HAL list absence or denied access is inconclusive; a listed service is not proof of a successful method call. Compare registered versus manifest-only entries in lshal. Record exact failures. Do not upload raw reports to public GitHub.

Acceptance: script completes and captures per-command status; device state unchanged; evidence sufficient to decide next diagnostic step. Device test pending. Native CLI implementation deferred until ABI and interface are verified. No LTE or eSIM activation claimed.
